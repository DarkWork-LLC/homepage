# PRIVACY POLICY

## YOUR PRIVACY MATTERS

THIS APPLICATION IS DESIGNED WITH PRIVACY AS A FUNDAMENTAL PRINCIPLE. **YOUR PERSONAL DATA AND NETWORK ACTIVITY NEVER LEAVE YOUR DEVICE.**

## DATA COLLECTION AND STORAGE

### LOCAL-ONLY OPERATION
- ALL USER DATA GENERATED BY THIS APP IS STORED **EXCLUSIVELY ON YOUR DEVICE**
- NO PERSONAL DATA, NETWORK ACTIVITY LOGS, OR DEVICE IDENTIFIERS ARE TRANSMITTED TO EXTERNAL SERVERS, CLOUD SERVICES, OR THIRD PARTIES
- NO ANALYTICS, TRACKING, OR TELEMETRY IS COLLECTED
- NO ACCOUNT OR REGISTRATION IS REQUIRED

### WHAT WE STORE (ON YOUR DEVICE ONLY)
THE APP STORES THE FOLLOWING INFORMATION LOCALLY ON YOUR DEVICE:
- APPLICATION SETTINGS AND PREFERENCES
- USER-CONFIGURED RULES AND FILTERS
- FIREWALL LOGS AND ACTIVITY RECORDS
- DOWNLOADED IP BLOCKLIST (THREAT INTELLIGENCE) DATA
- DATABASE ENTRIES CREATED WITHIN THE APP

ALL OF THIS DATA REMAINS ON YOUR DEVICE AND IS NEVER TRANSMITTED TO THIRD PARTIES.

## NETWORK ACTIVITY

### THREAT-INTELLIGENCE DOWNLOADS (ONE-WAY, READ-ONLY)
THE ONLY USE OF THE NETWORK IS TO DOWNLOAD PUBLICLY-AVAILABLE IP BLOCKLIST DATA SO THE FIREWALL CAN STAY CURRENT. THIS IS NOT USER TRACKING:
- COUNTRY IP RANGES ARE DOWNLOADED FROM **IPDENY** (`https://www.ipdeny.com/ipblocks/data/countries/`)
- THE P2P (PEER-TO-PEER) BLOCKLIST IS DOWNLOADED FROM THE **FIREHOL / IPSETS** PROJECT ON GITHUB (`https://raw.githubusercontent.com/firehol/blocklist-ipsets/master/firehol_level3.netset`)
- DOWNLOADS HAPPEN ON FIRST LAUNCH AND THEN APPROXIMATELY ONCE A WEEK IN THE BACKGROUND
- THE APP DOES **NOT** TRANSMIT ANY USER DATA, NETWORK ACTIVITY LOGS, PERSONAL INFORMATION, OR DEVICE IDENTIFIERS TO THESE SOURCES — IT ONLY FETCHES THE PUBLIC BLOCKLIST FILES
- NO DATA IS SENT TO EXTERNAL APIS OR SERVICES EXCEPT THE ONE-WAY FETCH OF PUBLIC BLOCKLIST FILES DESCRIBED ABOVE
- NO ADVERTISING, ANALYTICS, OR TRACKING SDKS ARE INCLUDED (NO AD SDKS)

### PERMISSIONS
THE APP MAY REQUEST CERTAIN DEVICE PERMISSIONS SOLELY FOR LOCAL FUNCTIONALITY:
- VPN / NETWORK PERMISSIONS: REQUIRED TO CREATE THE LOCAL VPN INTERFACE THAT INSPECTS AND FILTERS TRAFFIC ON-DEVICE (YOUR TRAFFIC IS NOT ROUTED OFF-DEVICE) AND TO DOWNLOAD PUBLIC IP BLOCKLIST UPDATES
- STORAGE PERMISSIONS: TO SAVE DATA LOCALLY ON YOUR DEVICE
- PACKAGE USAGE STATS / QUERY_ALL_PACKAGES: USED LOCALLY TO LIST APPS FOR FIREWALL RULES
- NOTIFICATION PERMISSIONS: TO SHOW LOCAL ALERTS WHEN BLOCKLIST DATA IS UPDATED
- OTHER PERMISSIONS: ONLY AS NEEDED FOR CORE APP FUNCTIONALITY, NEVER FOR DATA COLLECTION

## DATA CONTROL

### YOU HAVE COMPLETE CONTROL
- ALL DATA REMAINS UNDER YOUR CONTROL AT ALL TIMES
- YOU CAN DELETE ALL APP DATA THROUGH YOUR DEVICE SETTINGS
- UNINSTALLING THE APP REMOVES ALL ASSOCIATED DATA
- NO ACCOUNT CREATION OR PERSONAL INFORMATION IS REQUIRED

## THIRD-PARTY SERVICES

THIS APP ONLY INTERACTS WITH THIRD-PARTY SOURCES TO DOWNLOAD PUBLIC, NON-PERSONAL IP BLOCKLIST DATA:
- IPDENY (COUNTRY IP-RANGE ZONE FILES) — PUBLIC, READ-ONLY DOWNLOAD ONLY
- GITHUB / FIREHOL (P2P BLOCKLIST) — PUBLIC, READ-ONLY DOWNLOAD ONLY

## DATA SECURITY

SINCE ALL DATA REMAINS ON YOUR DEVICE:
- YOUR DATA IS PROTECTED BY YOUR DEVICE'S SECURITY MEASURES
- NO DATA IS VULNERABLE TO NETWORK INTERCEPTION
- NO DATA BREACHES CAN OCCUR FROM OUR SIDE (AS WE NEVER RECEIVE YOUR DATA)
- YOU MAINTAIN FULL OWNERSHIP AND CONTROL OF YOUR INFORMATION
