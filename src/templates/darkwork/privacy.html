Summary

Darkworks Lab performs its monitoring and analysis on the device where it is installed. The app does not operate a server for user data and does not intentionally transmit scan results, logs, sensor readings, filesystem results, or radio observations.

Information processed locally

Depending on permissions, hardware, platform, and the features used, the app may process:

  • Bluetooth device identifiers, names, addresses, signal strength, and advertisements.
  • Local network device names, addresses, interface details, host reachability, and open-port results.
  • Sensor readings such as accelerometer, gyroscope, magnetometer, ambient light, location, and battery state.
  • System telemetry such as device information, CPU, memory, battery, network interfaces, and sockets.
  • File names, paths, metadata, and scanner findings from locations available to the app.
  • SDR hardware status and radio-frequency observations when supported hardware is connected.
  • Application events, settings, and locally persisted logs.

How information is used

Information is used on-device to display monitoring status, perform scans, calculate local metrics, classify findings, and provide reports and logs. It is not used for advertising or an account-based service.

Permissions

Android permissions cover network access/state, Wi-Fi state, Bluetooth scanning/connectivity, location, notifications, and storage-related access. Runtime location and Bluetooth permissions are requested on the first launch on supported mobile platforms. Linux behavior depends on the host operating system and user account.

The app does not require every permission for every feature. Granting a permission increases the data and device capabilities available to that feature.

Storage, sharing, and retention

Logs and scan data are retained only as implemented by the relevant local service and platform storage. Data is not intentionally shared with third parties. Uninstalling the app normally removes app-private data; the user remains responsible for backups and exported files. The app provides no cloud account, cloud sync, or remote monitoring service.

User choices and deletion

Users can stop scans, disable streams where the UI exposes controls, clear supported logs/results, and uninstall the app to remove app-private data. Exported data must be removed by the user from the selected destination.

Limitations

A clean scan is not a guarantee of privacy, security, or absence of threats. The app cannot inspect inaccessible files, unavailable sensors, unsupported devices, or networks outside its reach.

Children

The app is not directed to children under 18. Do not use it to collect information about children.
