Bundled Tor runtime (status: 2026-09-17)

Android APKs now redistribute Tor native libraries through info.guardianproject:tor-android:0.4.8.16 from Guardian Project Maven, including transitive jtorctl. Tor itself is separate software (3-clause BSD) — https://www.torproject.org/. The Android wrapper, control client and native transitive components retain their respective upstream licenses. Desktop startup still uses a system or separately bundled Tor binary; iOS has no embedded Tor.framework integration.

This list is an overview, not a complete redistribution-notice bundle. Before shipping an APK, inventory all resolved Dart, Android and native dependencies, preserve required upstream copyright/license texts, and satisfy their respective redistribution obligations.
