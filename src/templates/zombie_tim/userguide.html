🧟 Zombie Tim - User Guide 🧟

Welcome to the official user guide for Zombie Tim, your favorite undead AI assistant! This guide will help you navigate the gory details of interacting with Tim and making the most of his decaying brain.

🚀 Getting Started

  1. Launch the App: Open Zombie Tim on your device.
  2. Initialize: On first run, Tim sets up his "Brain Database".
  3. Start Chatting: Use the bottom navigation to jump between screens. Type help in chat to see every command Tim knows.

📱 Main Interface

  • Chat (💬): The main interface for talking to Tim.
  • Scan (🔍): Tim can help you look through your device's storage.
  • Settings (⚙️): Customize Tim's behavior.

💬 Chatting with Tim

🧠 Special Commands

  • eat word <word>: Tells Tim to look up a specific word.
  • vocabulary: Shows a summary of what Tim has learned.
  • brain stats: Displays Tim's current IQ and total word count.
  • generate code <language> <description>: Tim writes code snippets.
  • magic 8 ball <question>: Ask Tim to predict the future!

📝 Personal Assistant

  • Reminders: remind me to [task] at [time]
  • Tasks: add task [description] due [date]
  • Notes: take note [content]

🌍 World Information

  • what time is it
  • weather
  • news
  • stock [symbol]

🔒 Security Monitoring

  • security scan: Perform a complete security audit.
  • check network: Quick network overview.
  • check bluetooth: Check Bluetooth devices and status.

Remember: Tim might be undead, but his passion for clean code is very much alive! 🧟‍♂️💻
