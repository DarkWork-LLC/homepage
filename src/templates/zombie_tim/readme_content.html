🧟 Zombie Tim 🧟

Zombie Tim is a cross-platform, AI-powered personal assistant with a twist—he's undead! Tim lives in your device and helps you manage your life while satisfying his hunger for knowledge (and brains).

Built with Flutter, Zombie Tim runs seamlessly on Android, iOS, Web, Linux, macOS, and Windows.

✨ Features

  • 🧠 Interactive Chat: Talk to Tim via a blood-splattered, animated interface. He responds with a unique zombie personality and learns from your conversations.
  • 📅 Proactive Assistant: Tim can manage your schedule:
    • Reminders: Set time-based alerts so you never forget a thing.
    • Task Management: Keep a "to-do" list with due dates and priorities.
    • Notes: Capture quick thoughts or detailed logs in Tim's digital brain.
  • 📚 Dynamic Vocabulary: Tim learns as you go. Use eat word <word> to expand his knowledge base.
  • 🔍 Brain Scanning: Tim can forage through your device storage to find information or "sniff out" new words from the web.
  • 💻 Developer Tools: Tim is a tech-savvy zombie. He can generate code snippets in various languages and explain complex technical concepts.
  • 🎱 Magic 8-Ball: Get undead predictions for your most pressing questions.
  • 🌍 World Information: Ask Tim about the weather, latest news, current time, or even stock prices.
  • 🐦 Social Media: Tim can interact with X/Twitter (login, fetch tweets, and reply).
  • 💻 System Integration: On desktop platforms, Tim can help with system tasks, run commands, and provide system status reports.
  • 🔒 Security Monitoring: Tim can perform security audits via chat commands - check your network connections, scan for suspicious activity, and monitor Bluetooth devices.

🔒 Security

Zombie Tim can perform security audits on your system via chat commands. Type security scan, check network, or check bluetooth in the chat interface to get detailed security reports.

Security Commands

  • security scan: Full security audit (network, Bluetooth, suspicious activity)
  • check network: Quick network overview
  • check bluetooth: Bluetooth device monitoring

All scans are performed locally on your device. No data is transmitted.

🔒 Privacy

Your data stays in your grave. All interactions, reminders, tasks, and notes are stored locally on your device using an encrypted-ready SQLite database. No personal data is sent to our servers.
