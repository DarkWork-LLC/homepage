Privacy Policy — online_snesgems_emulator

Effective date: November 14, 2026
Project: online_snesgems_emulator — a Django web application that emulates Super Nintendo (SNES) games in the browser and includes a WYSIWYG page editor.

1. No personal accounts or tracking

The application does not require you to create an account, does not collect your name, email address, or any other personally identifiable information, and does not run analytics, advertising, or tracking scripts. There are no third-party services, no external CDNs, and no social-media widgets integrated into the app.

2. Data that stays on your device (client-side)

The SNES emulator runs entirely in your web browser (Snes9x compiled to WebAssembly). The following data is stored only in your browser and is never sent to the server:

  • Save states: IndexedDB (database snes-emu, store save-states) — Save and reload in-game progress.
  • Cartridge SRAM / battery-backed saves: Origin Private File System (OPFS) — Persist game saves across sessions.
  • Button / key bindings: localStorage — Remember your controller remapping.
  • Audio mute preference: localStorage / in-memory config.

3. Data stored on the server (Django backend)

The Django backend stores ROM library metadata, WYSIWYG pages authored through /wysiwyg/, and standard Django admin user credentials in SQLite (db.sqlite3).
