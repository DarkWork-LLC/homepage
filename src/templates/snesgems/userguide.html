User Guide — online_snesgems_emulator

A Python-Django web application that runs Super Nintendo (SNES) games directly in your web browser, plus a Django WYSIWYG rich-text page editor.

1. Overview

The emulator runs client-side in your browser (Snes9x compiled to WebAssembly). The Django backend only serves the user interface, the ROM library metadata, and the binary ROM streams; the emulation itself happens locally, so there is no server-side lag during play.

The app also includes a WYSIWYG rich-text page editor at /wysiwyg/ for authoring HTML pages backed by SQLite.

2. System requirements

  • A modern desktop or mobile browser with WebAssembly and IndexedDB support (Chrome, Edge, Firefox, Safari).
  • A secure context for save states: https:// in production, or http://localhost when running locally.

3. First launch

pip install -r requirements.txt
python manage.py migrate
python manage.py seed_roms
python manage.py runserver

Then open https://hoobylab.pythonanywhere.com/ or local development server.

4. Playing a game

  1. Open the app. The ROM library lists the bundled games.
  2. Click a game card (or select it from the dropdown) to load it.
  3. Press Play to start emulation.

5. Controls

Supports Keyboard (Arrow keys + SNES diamond mapping), USB Gamepads, and On-screen Virtual Gamepad (touch, mouse, and trackpad support with visual glow feedback).

10. WYSIWYG page editor

Use the editor at /wysiwyg/ to create, edit, preview, and delete rich-text pages using native browser content editing.
