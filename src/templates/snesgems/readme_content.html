Online SNES Gems Emulator

A Python-Django web application that runs Super Nintendo (SNES) games directly in your web browser — playable on a desktop browser, a mobile phone or a trackpad — with save states persisted in the user's browser. It also includes a Django WYSIWYG rich-text page editor (/wysiwyg/) for authoring pages that can be deployed on PythonAnywhere.

How it works

The emulation runs client-side in the browser (Snes9x compiled to WebAssembly, vendored under static/snes/js/vendor/). The Django backend serves the UI, the ROM metadata and the binary ROM streams; the heavy lifting happens in the browser, so there is no server-side latency and the app can run on a modest host.

Features

  • Play bundled games in the browser (canvas rendering).
  • Controls: keyboard (arrows + SNES diamond layout), USB gamepads (polled automatically), on-screen virtual gamepad (touch + mouse + trackpad) with D-pad, shoulder buttons (L/R, Select, Start), action diamond (X,Y,A,B), and draggable thumbstick.
  • Button Configuration: Reassign key bindings for all 12 controller buttons with localStorage persistence.
  • Visual Feedback: Blue flash / glow effect when touching or clicking on-screen buttons.
  • Audio Support: Robust Web Audio handling with Mute toggle and browser autoplay policy unlock.
  • Save states are stored in the user's browser (IndexedDB) and can be reloaded later — no server round-trip.
  • Cartridge SRAM (battery-backed saves) is auto-persisted to the browser's Origin Private File System (OPFS) every 15 s and on pause/destroy.
  • In-game settings menu (press Escape) for region, aspect, filter, volume, interpolation, sprite limit, etc.
  • WYSIWYG rich-text page editor at /wysiwyg/ — create, edit, preview and delete pages with formatted HTML content, backed by SQLite and the Django admin. No frontend build step or external CDN required.
